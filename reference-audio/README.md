# Reference audio

This folder holds reference recordings used to build Kindling's first creative assets. They are kept in the repo as research provenance: anyone can see and hear exactly what the first models were built from.

## First reference: the owner's voice

- **File:** `ain't myself lost on earth.wav`
- **What:** The owner's own recording of his song "Ain't Myself Lost On Earth" (3 minutes, stereo 44.1 kHz).
- **Used for:** The first voice character, `voice_aries` ("Aries"), v1, built 2026-10-17. See `voice-characters/aries_v1.json`.
- **Analysis result:** Sufficiency report passed with no gaps. Five distinct vowel states, full chest/mix/head register coverage, three minutes of voiced material.
- **Consent:** On file. The owner directed its use himself.
- **Honest caveat:** The reference is a mastered full mix, not an isolated vocal, so the identity vector includes mix bleed. An a cappella reference would sharpen it later.
